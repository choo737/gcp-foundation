# Data Platform Stages

Choose between a fast single-project sandbox or a five-project enterprise layout.

## Paths

- `sandbox/`: One project with Medallion datasets, `LAST_FOUR_CHARACTERS` masking, Dataplex scan, and Dataform.
- `enterprise/`: Split governance, storage, domain mart, ETL compute, and BI compute projects.

Both paths use `https://github.com/choo737/gcp-data-medallion.git` by default.
