# Data Platform Stages

Choose between a fast single-project sandbox or a four-project enterprise layout.

## Paths

- `sandbox/`: One project with Medallion datasets, `LAST_FOUR_CHARACTERS` masking, Knowledge Catalog (formerly Dataplex) scan, and Dataform.
- `enterprise/`: Split governance, core storage/ETL, domain mart, and BI compute projects.

Both paths use `https://github.com/choo737/gcp-data-medallion.git` by default.
